# Warhammer 40K: Rogue Trader VR — 0.9.81 beta

## Highlights

- More flexible positioning for dialogue, management, large tutorial and tip panels, with corrected clipping and revised defaults.
- Shared horizontal, vertical and distance controls for the mod menu and its tutorial.
- Unified management-panel settings while retaining native game navigation.
- Improved camera follow around scenery and 40% faster default stick rotation and tilt.
- DLSS and DLAA model selection: Automatic, J, K, L and M, subject to runtime support.
- A main-menu switch for monitor output, useful for optional performance comparisons.
- Restored experimental OFXR compatibility with DLSS/DLAA.

## Installation and settings

Extract the complete ZIP to a new folder and run INSTALL.cmd with the game closed. When upgrading an earlier version, the installer asks before resetting mod settings and saved layouts, creates and verifies a recoverable backup, and displays its location. The selected runtime, chosen DLSS DLL and unrelated mods are preserved. Reinstalling 0.9.81 preserves current settings.

Continuous diagnostics and OFXR start off. After installation, open LAUNCH-VR.cmd and select your headset and connection. Restart the game after changing OFXR. The in-game status reports actual synthesis; enabling the checkbox alone is only a request.

Meta Quest: Virtual Desktop/VDXR or Meta Quest Link/Air Link. PICO 4/Ultra: Virtual Desktop/VDXR. Pimax Dream Air SE/Air SLAM: Pimax Play native OpenXR.

This remains an experimental beta. No measured FPS gain or parity claim is made. Hand tracking is not included. See the bundled guide and third-party notices for requirements, credits and licenses.
